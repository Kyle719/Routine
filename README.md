# Routine

설치 없이 실행되는 로컬 저장형 루틴 트래커입니다. PC와 Android 브라우저에서 사용할 수 있고, PWA로 설치하면 앱처럼 실행됩니다.

## 개발

Windows에서 Node.js가 설치되어 있으면 프로젝트 폴더에서 실행합니다.

```powershell
node .\dev-server.mjs
```

브라우저에서 [http://localhost:4173](http://localhost:4173)을 열어 사용합니다. HTML, CSS, JavaScript를 저장하면 개발 페이지가 자동으로 새로고침됩니다.

Android 기기에서 설치하려면 앱을 HTTPS를 지원하는 정적 호스팅에 배포한 다음 Chrome에서 열어 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 개발 PC와 같은 Wi-Fi에서 확인할 때는 PC의 로컬 IP 주소와 포트 4173으로 접속할 수 있지만, PWA 설치 기능은 브라우저의 보안 연결 정책에 따라 HTTPS가 필요합니다.

## 데이터

루틴과 완료 기록은 브라우저의 `localStorage`에 저장되며 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 앱 기록도 사라집니다. 앱의 설정 메뉴에서 **모든 데이터 삭제**를 선택하면 이 기기의 저장 내용을 초기화할 수 있습니다.

운영체제의 화이트/다크 테마 설정을 따라갑니다. 주간 달력은 일요일부터 시작하며 과거 달도 조회할 수 있습니다.
